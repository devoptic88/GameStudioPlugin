# Crownfall Tactics

A browser-based fantasy lane battler inspired by real-time card strategy games.

## Features

- Phaser + TypeScript + Vite
- Card deployment with elixir economy
- Ground and flying units
- Bridge-based river pathing
- Side-tower priority with direct tower targeting
- AI-generated character art with front/back views
- Animated cards and units
- Synthesized music and character-specific spawn/hit sounds

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is emitted to `dist/`.

## Deploy

Deploy the `dist/` folder to any static host, or connect the repo to Vercel/Netlify with:

- Build command: `npm run build`
- Output directory: `dist`
